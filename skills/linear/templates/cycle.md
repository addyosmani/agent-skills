# Cycle record and cycle review

The record goes in the cycle description when it is planned; the review is a comment on the cycle at close. A rolled-over issue is re-estimated with its reason, never silently carried.

```markdown
## Cycle <n> — <start> → <end> — milestone <name>
- Goal: <what is usable at the end>
- Capacity: <points> (basis: last cycle delivered <points> | assumption)
- Planned: <points> across <n> issues

### Cycle review
- Delivered: <points> (<n> issues)
- Rolled over: <points> — <issue: reason, re-estimated to n>
- Estimation error: <issue: estimated n, actual m, cause>
- Unplanned work: <issue: points, why>
- Blockers hit: <issue: blocker type, resolution>
- Next cycle capacity: <points> (basis)
```
