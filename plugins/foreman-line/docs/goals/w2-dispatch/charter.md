## Objective

Ship Wave 2 of the Foreman Line (FOREMAN-LINE-PLAN.md §8, "W2 — Dispatch"): the pipeline's Stage C capability — Jira query + next-candidate ranking → model routing evaluation → skill injection resolution → Kompress context compression → Step 0 pre-draft + one-tap human approval → DispatchOrder emitted with dispatch receipt — built parcel by parcel under PDD against the frozen W0 contracts and W1 packages.

## Exit criterion

A registered parcel — SCAF-P2 (KONE-23195, already shaped/approved/registered) — dispatched to a builder session through the W2 machinery: the dispatcher queries Jira and surfaces SCAF-P2 as the candidate, the routing engine selects the model, the skill injection engine resolves the injected skills from SCAF-P2's `surfaces:`, Kompress compresses the parcel spec, the Step 0 restatement is pre-drafted, Clint approves with one tap, and a schema-valid `DispatchOrder` + Stage-C dispatch receipt are emitted. SCAF-P2's builder session then builds and ships the shared test-scaffold extraction end-to-end (SCAF-P2 is the real work, not a synthetic proof). The receipt chain must be walkable: genesis → Stage-A (W1) → Stage-B (W1) → Stage-C (W2).

## Stop conditions

Universal set (COORDINATOR-PATTERN): a frozen contract needs modification; a tripwire fires twice on one parcel; a security finding can't close in-parcel; anything outward-facing beyond the standing authorizations; queue empty. Goal-specific additions: any Jira write outside KONE during W2-P1 (read-only boundary — a write attempt is a stop, not a ruling); headroom MCP unreachable or the compress/retrieve round-trip fails at W2-P4 shaping time (stop rather than weakening the Kompress guarantee); `DispatchOrder` schema incompatibility with the frozen `c-dispatch.ts` contract (loop-stop, not a ruling).
